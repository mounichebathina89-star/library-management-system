# ⚡ Quick Start

Get LibraryHub running in 5 minutes!

## TL;DR Commands

### Terminal 1 (Backend)
```bash
cd server
npm install
cp .env.example .env
# Edit .env and add your MongoDB URI
npm run seed
npm run dev
```

### Terminal 2 (Frontend)
```bash
cd client
npm install
npm run dev
```

## Then Open
- 🌐 Frontend: `http://localhost:5173`
- 🔌 Backend API: `http://localhost:5000/api`
